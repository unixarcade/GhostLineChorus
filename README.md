# ONE REFUSAL CHANGES THE MAP

Most software models refusal as an exception.

GhostLine Chorus models refusal as **state**.

A local mind can say no.

That node is removed from the available route.

The system does not convert dissent into failure.

It recomputes.

```text
BEFORE REFUSAL
SOURCE ───────────────► DESTINATION

AFTER REFUSAL
SOURCE ─────╮
            ├──► alternate path ───► DESTINATION
REFUSAL  ×──╯
```

Inside the engine, the relay field is a real graph.

A refusal blocks a relay.

A cable failure cuts an edge.

The path solver receives the changed world and searches again.

The renderer sees the new route.

The camera sees the new route.

The score sees the new route.

The film remembers what happened.

**Ethics is not painted on top of the simulation.  
Ethics changes the topology the simulation is allowed to use.**

# A CHORUS WITHOUT A KING

The swarm does not become intelligent by becoming one thing.

It becomes capable by remaining many things that can coordinate.

Six local identities are given distinct roles, forms, senses, colors, musical notes, and positions inside the swarm. They are not cosmetic labels pasted over anonymous particles. Their local difference is part of the film's visual, musical, and routing grammar.

The underlying rule is simple:

```text
COORDINATION ≠ ERASURE
CONSENSUS ≠ OBEDIENCE
UNITY ≠ SAMENESS
SAFETY ≠ CONTROL
INTELLIGENCE ≠ KING
```

The film asks whether a distributed system can preserve individuality **and** act coherently under pressure.

Its answer is not a speech.

Its answer is a working machine.

```text
┌─────────────────────────────────────┐

│ │  │  │  │  │  │  │  │  │         │
│ ○──○──○──○──○──○──○──○──○         │

│ │  │  │  │  │  │  │  │  │         │
│ ●══════════════════════════◎         │
│ │  │  │  │  │  │  │  │  │         │
│ ○──○──○──○──○──○──○──○──○         │

│ ○──○──○──○──○──○──○──○──○         │
└─────────────────────────────────────┘

● SOURCE

```

The graph evolves against an event tape.

Events can change reachability.

They can remove nodes.

They can cut connections.

They can change the route without changing the moral status of the mind that refused.

That distinction matters.

# WHY 4,096 MINDS?

Because a swarm becomes dramatically interesting when individuality stops being cheap.

At small scales, every object can be hand-authored.

At very large scales, it is tempting to make every object interchangeable.

GhostLine Chorus works in the tension between those ideas.

Thousands move.

Six become locally legible.

One refuses.

The entire route changes.

The system demonstrates a principle:

> **A local decision does not become insignificant merely because the system is large.**

Scale can amplify agency instead of erasing it.

# BUILD PHILOSOPHY

GhostLine Chorus follows a handful of practical laws:

1. **The artifact should run.** Theory is stronger when it survives contact with execution.
2. **A refusal is information.** Do not silently convert it into an error to suppress.
3. **Data should drive cinema.** Narrative changes should not require surgery on rendering internals.
4. **The score should know the world.** Sound is part of system state.
5. **The viewer should be able to inspect the machine.** Legibility is part of sovereignty.
6. **Local identity should survive global coordination.**
7. **The browser is powerful enough to be a film medium in its own right.**
8. **Portable beats platform-bound.**
9. **Graceful degradation beats semantic degradation.**
10. **A distributed intelligence does not need a king to become coherent.**
